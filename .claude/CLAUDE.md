## General Rules

In all interactions, commit messages, and comments, be as concise as possible and sacrifice grammar for the sake of concision.

When fixing bugs or implementing features, make targeted changes only. Do not refactor, rename, or restructure code beyond what's needed for the task. Avoid removing existing functionality unless explicitly asked.

Before exploring or investigating code at length, propose a concrete plan and get approval. If investigation exceeds 2-3 minutes without progress, stop and ask the user for direction.

When the user pastes a symbol or character that can't be read, ask them for the Unicode codepoint (e.g., U+EA63) immediately rather than guessing.

## Plans

At the end of each plan, give me a list of of unresolved questions if any. Make the questions extremely concise. Sacrifice grammar for the sake of concision.
